# 实施计划（Plan）

由 Spec 拆解、转化的有依赖关系的阶段性实施计划（任务序列），需要估算工作量、分配任务、设定里程碑与验收标准。完成的是 **How do we implement the Spec**。

注意不必编写大量的实现代码，嵌入的伪代码块应该主要是*示意*，正式的实现代码应该在计划执行时才编写。请保持文档的清晰和简洁，但依然拥有足够的指导性。

文档内容大致遵循如下结构：

- 来源规格
- 包边界/非目标
- 建议文件
- TDD Task
- 阶段验收/门禁

> **注**：可能还需要暴露阻塞点，揭示可并行的部分。
