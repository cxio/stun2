# 技术规格（Spec）

定义目标具体什么样，精确的技术规格。如模块划分、接口与数据设计、字节编码、字段宽度、实现的细则等。完成的是 **What exactly must the system do**。

该部分由 AI 根据 Conception 和 Decision 的内容分析创建出来，注意在精简精炼和足够的细节之间保持平衡。衡量标准是：Plan 可以遵循这些细粒度规格编写实现计划而不需要自由发挥。

文档内容大致遵循如下结构：

- 来源追溯
- 概述
- 规格正文
- 边界与限制
- 待决问题
- 对 Plan 的约束
